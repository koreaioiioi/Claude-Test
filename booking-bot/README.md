# amanopark-booking-bot

`valet.amanopark.co.kr/booking` 페이지에서 예약을 계속 시도하다가, 예약이 성공하면 자동으로 멈추는 프로그램입니다.
Playwright로 실제 브라우저를 띄워 폼을 채우고 제출한 뒤, 결과(성공/마감/오류)를 판별해서 반복합니다.

## ⚠️ 실행 전 꼭 읽어주세요

1. **이 코드는 실제 사이트 구조를 직접 확인하지 못한 상태로 작성되었습니다.**
   `selectors.js`의 값은 전부 자리표시자(placeholder)입니다. 실제 페이지의 입력창/버튼/결과 문구에 맞게
   반드시 수정해야 동작합니다. (아래 "실제 사이트에 맞게 설정하기" 참고)
2. 이 프로그램은 실제 서버에 반복적으로 요청을 보냅니다. 이용약관 위반 소지가 있고, 너무 짧은 간격으로 돌리면
   상대 서버에 부담을 줄 수 있습니다. 기본값(40~70초 랜덤 간격)보다 더 짧게 설정하지 않는 것을 권장하며,
   본인 명의의 정상적인 예약 목적으로만, 자기 책임 하에 사용하세요.
3. 캡차/SMS 인증 같은 사람 확인 절차가 나타나면 이 프로그램은 그것을 우회하지 않습니다.
   (그런 절차는 자동화하지 않도록 의도적으로 설계했습니다.) 만약 실제 사이트에 그런 단계가 생기면
   프로그램이 상태를 인식하지 못해 3회 연속 "unknown"으로 스스로 멈추도록 되어 있습니다.

## 설치

```bash
cd booking-bot
npm install
npx playwright install chromium   # 처음 한 번만: 브라우저 바이너리 설치
cp .env.example .env
```

`.env` 파일을 열어 예약자 이름/연락처/차량번호/원하는 날짜·시간을 채워주세요.

## 실제 사이트에 맞게 설정하기 (가장 중요)

1. 크롬으로 `https://valet.amanopark.co.kr/booking` 접속 → F12(개발자도구) 열기
2. 이름/연락처/차량번호/날짜/시간 입력창, 제출 버튼을 각각 우클릭 → **검사(Inspect)**
3. Elements 패널에서 해당 태그 우클릭 → **Copy → Copy selector**
4. `selectors.js`의 `form.name`, `form.phone`, `form.carNumber`, `form.date`, `form.time`, `form.submit` 값을
   복사한 셀렉터로 교체
5. 예약 제출 후 "성공" 메시지와 "마감/불가" 메시지가 각각 어떤 문구/요소로 나타나는지 확인해서
   `selectors.js`의 `outcome.success`, `outcome.noSlot` 값도 맞게 수정
   - 특정 영역(예: `<div class="alert">`)에만 나타난다면 `{ selector: '...' }`
   - 페이지 어디든 특정 문구가 뜨면 된다면 `{ text: '예약이 완료되었습니다' }`
6. 폼이 단순 입력창이 아니라 "달력에서 빈 시간을 클릭"하는 방식이라면, `bot.js`의 `attemptBooking()` 함수에서
   날짜/시간을 입력하는 부분을, 원하는 시간대에 해당하는 (비활성화되지 않은) 슬롯 요소를 찾아 클릭하는 코드로
   바꿔야 합니다.

먼저 `HEADLESS=false`로 설정해두고 한두 번 실행해서 브라우저가 실제로 어떻게 동작하는지 눈으로 확인하는 것을
추천합니다.

## 실행

```bash
npm start
```

성공할 때까지(또는 설정한 최대 시도/시간에 도달할 때까지) 계속 재시도합니다. 중단하려면 `Ctrl+C`.

- 로그: `logs/booking-bot.log`
- 성공 시 스크린샷: `logs/success-*.png`
- 성공/중단 시 `.env`의 `WEBHOOK_URL`(Slack/Discord 등 Incoming Webhook)로 알림 전송 (선택 사항)

## 데모 (실제 사이트 접속 없이 동작 확인)

로컬에 가짜 예약 페이지를 띄워서, 재시도 로직만 안전하게 확인해볼 수 있습니다.

```bash
npm run demo
```

## 동작 방식 요약

- 매 시도마다 새 브라우저 컨텍스트로 예약 페이지 접속 → 폼 입력 → 제출 → 결과 판별
- 결과가 "마감/실패"면 40~70초(설정 가능) 사이 무작위 대기 후 재시도
- 결과가 "성공"이면 스크린샷 저장 후 즉시 종료
- 결과를 3회 연속 판별하지 못하면(즉, `selectors.js` 설정이 실제 페이지와 안 맞을 가능성이 높으면)
  무한 재시도로 서버에 부담을 주지 않도록 스스로 종료
- `.env`의 `MAX_ATTEMPTS`, `MAX_RUNTIME_MINUTES`로 최대 시도 횟수·실행 시간 제한 가능 (비워두면 무제한)

## 참고: 이 세션(클라우드 샌드박스)에서는 직접 실행할 수 없습니다

이 코드를 작성한 클라우드 환경은 네트워크 정책상 `valet.amanopark.co.kr`에 접속할 수 없어서, 실제 사이트를
대상으로 한 테스트는 하지 못했습니다. 대신 로컬 가짜 서버(`npm run demo`)로 재시도/성공 판별 로직 자체는
검증했습니다. 실제 사용은 이 사이트에 접속 가능한 본인 컴퓨터나 서버에서 진행해주세요.
